Implemented now

Current reference-stack capabilities.

Consensus

Public UTXOs, 75-second target, eight bootstrap eras, 0.0625 ATHO finite tail, 168 million ATHO cap, and an adaptive block budget.

Authorization

Falcon-512 wallet signatures and SHA3-384 proof-of-work block production.

Network privacy

Mandatory hybrid encrypted P2P with Falcon node identity on public modes.

Interfaces

Polished desktop client plus node, CLI, miner, wallet, and address binaries.

Storage and sync

Headers-first sync, compact relay, reorgs, pruning, archive mode, validated indexes.

Local controls

Authenticated loopback RPC and loopback HTTP with gated write capabilities.

Launch discipline

Evidence before promises.

Stable operation matters, but public launch requires a broader body of evidence.

01

Freeze the compatible consensus, genesis, monetary, and transport rules.

02

Publish test vectors, signed reproducible releases, checksums, and upgrade notes.

03

Complete independent cryptography, consensus, wallet, P2P, RPC, and deployment review.

04

Run a fresh hostile public testnet on the final ruleset with independent infrastructure.

05

Resolve material findings and rehearse monitoring, backup, incident, and recovery procedures.

Scope boundary

Research is not shipped functionality.

Private transaction layers and state-channel architectures are not part of the current implementation. They are intentionally excluded from this site's feature claims and protocol downloads.
