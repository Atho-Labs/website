Testnet Flow

  • Build with cargo build or cargo build --release.
  • Run python3 run/runtestnet.py to open the client.
  • Create or import a wallet, sync to the network, then mine or send test transactions.
  • Request testnet ATHO from the Atho team when wallet testing needs funds.
