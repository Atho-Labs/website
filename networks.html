Network modes

Four modes, intentionally separated.

Mainnet, testnet, regnet, and prunetest use distinct identities, ports, storage paths, address prefixes, and genesis state. A mode being implemented does not mean a public network is currently online.

Current directory

Identity, ports, and availability.

The previous public testnet has been retired. Regnet remains the recommended local development mode.

Isolation boundaries

Choose the mode before starting any tool.

Nodes, wallets, miners, and CLI clients should all target the same explicit network. Keeping each mode in its own data directory prevents incompatible chains and wallet state from being mixed.

Separate identity

Each mode uses its own consensus identifier, P2P magic, and genesis anchor.

Separate interfaces

P2P and loopback RPC ports are unique to each network mode.

Separate storage

Chain, peer, and wallet data stay scoped to the selected mode.

Local development

Start with regnet.

Regnet provides a disposable local chain for integration work while no public Atho network is online.

./target/release/athod --network regnet
./target/release/atho-cli --network regnet getblockchaininfo

Explicit network identities for production, testing, and local development.
